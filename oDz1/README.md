# Rain in Australia — анализ и сравнение моделей

## 1. Выбор датасета

Для исследования был выбран датасет **Rain in Australia**.

Он оказался первым бинарным датасетом в предложенном списке. Кроме того, мне интереснее исследовать взаимосвязи, связанные с дождём, поскольку эта тема мне понятнее, чем анализ грибов или закупок.

## 2. Проверяемые гипотезы

В ходе исследования были сформулированы следующие гипотезы:

1. Если убрать признаки, связанные с ветром, модель будет предсказывать лучше.
2. Если заполнять пропущенные значения средним вместо медианы, качество модели ухудшится.
3. `LogisticRegression` будет предсказывать лучше, чем `RandomForestClassifier`.
4. Если увеличить параметр `min_samples_leaf` у `RandomForestClassifier`, качество модели улучшится.
5. Если уделять больше внимания классу `RainTomorrow = Yes` с помощью `class_weight='balanced'`, модель будет лучше находить дождливые дни.

## 3. Результаты проверки гипотез

В результате экспериментов подтвердилась только **пятая гипотеза**, остальные четыре были опровергнуты.

| № | Гипотеза | Результат |
|---|---|---|
| 1 | Удаление признаков ветра улучшит предсказания | ❌ Не подтвердилась |
| 2 | Заполнение пропусков средним ухудшит качество | ❌ Не подтвердилась |
| 3 | LogisticRegression будет лучше RandomForest | ❌ Не подтвердилась |
| 4 | Увеличение `min_samples_leaf` улучшит качество | ❌ Не подтвердилась |
| 5 | `class_weight='balanced'` улучшит поиск дождливых дней | ✅ Подтвердилась |

## 4. Итог

Лучший результат показал **`RandomForestClassifier`**.

Использование `class_weight='balanced'` позволило значительно повысить полноту (**recall**) для класса дождливых дней (`RainTomorrow = Yes`), хотя при этом общая точность (**accuracy**) снизилась.

Таким образом, балансировка весов классов помогла модели лучше обнаруживать дождливые дни, даже несмотря на некоторое снижение общей точности предсказаний.
